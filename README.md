# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the Linux environment and basic cloud computing concepts. I explored an Ubuntu 24.04 environment, checked system information, created a workspace, and documented my activities using Markdown and GitHub.

## Objectives

- Explore the Ubuntu Linux environment.
- Identify basic system information.
- Create and organize directories and files.
- Use Linux commands through the terminal.
- Create and edit Markdown files.
- Document laboratory activities using GitHub.

## Activities Performed

1. Launched an Ubuntu 24.04 Linux environment using KillerCoda.
2. Investigated the Linux distribution, kernel version, CPU, memory, and disk space.
3. Created the `Notes`, `Reports`, and `Screenshots` folders.
4. Created and edited the `about-me.md` Markdown file.
5. Created a GitHub repository for my Cloud Computing laboratory portfolio.
6. Created and organized the Laboratory 01 files.
7. Created a reflection about what I learned from the laboratory.
